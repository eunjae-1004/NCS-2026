너는 교육/컨설팅용 검색 웹앱 UI를 만드는 프론트엔드 개발자다.

현재 FastAPI 검색 API가 준비되어 있다.

API는 사용자가 입력한 부서명, 직무명, 직무 설명을 기반으로 추천 세분류, 수행직무, NCS 능력단위를 반환한다.

목표:
비개발자도 쉽게 사용할 수 있는 NCS 직무·능력단위 추천 웹앱을 만든다.

요청사항:

1. React 또는 순수 HTML/CSS/JavaScript 중 단순하고 유지보수 쉬운 방식으로 작성해줘.
2. 모바일에서도 보기 좋게 반응형으로 작성해줘.
3. API 주소는 config 파일에서 관리하게 해줘.
4. README.md에 실행 방법을 작성해줘.

화면 제목:

NCS 직무·능력단위 추천 시스템

설명 문구:

부서명, 직무명 또는 직무 설명을 입력하면 관련 세분류, 수행직무, NCS 능력단위를 추천합니다.

화면 구성:

- 검색 입력창
- 검색 버튼
- 예시 입력 버튼
- 추천 세분류 영역
- 추천 직무 영역
- 추천 능력단위 영역
- 세분류별 능력단위 체크리스트
- 선택한 직무 구성 영역

예시 입력:

- 품질팀
- 생산관리
- 불량 원인을 분석하고 개선대책을 수립한다
- 품질팀에서 수입검사와 불량 개선 업무를 수행한다

세분류 UI:

1. 추천 세분류 Top 3를 카드 형태로 표시해줘.
2. 카드에는 다음 정보를 표시해줘.

- 세분류명
- 적합도 점수
- 추천 근거
- 매칭 키워드

3. 세분류 카드를 클릭하면
GET /api/subcategories/{subcategory_code}/units
API를 호출해 능력단위 체크리스트를 표시해줘.

능력단위 UI:

1. 사용자는 능력단위를 체크할 수 있어야 한다.
2. 체크된 능력단위는 “선택한 직무 구성” 영역에 누적 표시해줘.
3. 추천 능력단위에는 다음 정보를 표시해줘.

- 능력단위명
- 능력단위요소명
- 추천 점수
- 추천 근거

검색 UX:

1. 검색 중에는 “검색 중입니다” 메시지를 표시해줘.
2. 검색 결과가 없으면 다음 메시지를 표시해줘.

“추천 결과가 없습니다. 다른 표현으로 입력해 주세요.”

디자인 조건:

1. 교육/컨설팅 데모에 적합한 화면으로 구성해줘.
2. 과도한 애니메이션은 사용하지 않는다.
3. 깔끔하고 신뢰감 있는 UI로 구성해줘.
4. 추천 점수는 0~100점 형태로 표시해줘.
5. 세분류 추천 → 직무 추천 → 능력단위 추천 흐름이 한눈에 보이게 구성해줘.

확장 고려사항:

1. 추후 로그인 기능 추가 가능하도록 구성해줘.
2. 추후 관리자 화면 추가 가능하도록 구성해줘.
3. 추후 동의어 사전 관리 기능 추가 가능하도록 구성해줘.
4. 너무 복잡한 구조는 사용하지 않는다.
