너는 PostgreSQL, Python, pandas, SQLAlchemy 기반 데이터 전처리에 능숙한 개발자다.

현재 NCS 기준정보 추천 시스템을 개발 중이다.

목표는 사용자가 부서명, 직무명, 직무 설명 또는 복합 문장을 입력했을 때 적합한 세분류, 수행직무, NCS 능력단위를 추천하는 것이다.

PostgreSQL에는 다음 테이블이 존재한다.

원본 테이블:
1. T11_NCS_UNITS
2. T12_PERFORMANCE_CRITERIA
3. T13_KSA
4. T14_SUBCATEGORY_DEFINITIONS
5. T15_UNIT_DEFINITIONS

전처리/검색 테이블:
1. T21_DEPARTMENT_DICTIONARY
2. T22_JOB_DICTIONARY
3. T23_DEPARTMENT_JOB_MAPPING
4. T24_JOB_UNIT_MAPPING
5. T25_NCS_SEARCH_INDEX
6. T26_SEARCH_TEST_CASES
7. T27_NCS_EMBEDDINGS
8. T28_SEARCH_RESULT_LOG

요청사항:

1. Python ipynb 또는 py 파일로 전처리 코드를 작성해줘.
2. .env 파일에서 PostgreSQL 접속정보를 읽도록 해줘.
3. pandas, sqlalchemy, psycopg2를 사용해줘.
4. 함수 단위로 코드를 분리해줘.
5. 오류 발생 시 어느 단계에서 오류가 발생했는지 로그를 출력해줘.
6. README.md에 실행 순서를 작성해줘.

T25 생성 규칙:

1. T11_NCS_UNITS를 중심 테이블로 사용한다.
2. T25_NCS_SEARCH_INDEX는 실행 시마다 TRUNCATE 후 다시 INSERT한다.

조인 규칙:

1. T11 ↔ T12 수행준거

T11.unit_element_id = T12.unit_element_id
AND T11.unit_category_id = T12.unit_category_id

2. T11 ↔ T13 KSA

T11.unit_element_id = T13.unit_element_id
AND T11.unit_category_id = T13.unit_category_id

3. T11 ↔ T14 세분류정의

T11.subcategory_code = T14.subcategory_code

4. T11 ↔ T15 능력단위정의

T11.unit_category_id = T15.unit_category_id

전처리 규칙:

1. 수행준거는 unit_element_id + unit_category_id 기준으로 groupby 하여 performance_criteria_text로 통합해줘.

2. KSA는 unit_element_id + unit_category_id 기준으로 groupby 후,
ksa_type 기준으로 다음 컬럼으로 분리해줘.

- knowledge_text
- skill_text
- attitude_text

3. integrated_search_text에는 다음 내용을 모두 합쳐줘.

- 대분류명
- 중분류명
- 소분류명
- 세분류명
- 능력단위명
- 능력단위요소명
- 능력단위 정의
- 세분류 정의
- 수행준거
- 지식
- 기술
- 태도

4. normalized_search_text에는 다음 정규화를 적용해줘.

- 소문자 변환
- 특수문자 제거
- 중복 공백 제거
- 앞뒤 공백 제거

5. keyword_text에는 다음 중심으로 핵심 키워드를 생성해줘.

- 세분류명
- 능력단위명
- 능력단위요소명

6. subcategory_search_text에는 세분류 추천을 위해 다음 내용을 세분류 단위로 통합해줘.

- 세분류명
- 세분류 정의
- 해당 세분류의 능력단위명
- 능력단위요소명
- 수행준거
- KSA

7. subcategory_keyword_text에는 세분류명과 대표 능력단위명을 중심으로 생성해줘.

PostgreSQL Full Text Search:

1. search_vector를 생성해줘.
2. search_vector는 다음 내용을 합쳐 생성해줘.

- normalized_search_text
- keyword_text
- subcategory_keyword_text

3. PostgreSQL to_tsvector 함수를 사용해줘.

T27 임베딩 준비:

1. T27_NCS_EMBEDDINGS 생성 함수는 별도 함수로 분리해줘.
2. 현재 단계에서는 실제 embedding vector 생성 없이 embedding_text만 저장한다.
3. embedding_text는 integrated_search_text를 기반으로 생성한다.
4. 향후 OpenAI, Ollama, HuggingFace embedding 모델을 연결할 수 있도록 함수 구조를 분리해줘.
5. embedding_text가 너무 길 경우 일정 길이로 자를 수 있게 해줘.

최종 출력:

1. T25 row count 출력
2. subcategory_code별 row count 출력
3. 샘플 데이터 10건 출력
4. 오류 발생 시 상세 로그 출력
